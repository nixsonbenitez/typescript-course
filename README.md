# 🚀 Koda TypeScript Course

My 12-week journey learning TypeScript, React Native, and Supabase — building toward my app, **Koda**.

**Pace:** ~30 min/day, 5 days a week.
**Started:** Week of July 26, 2026.

---

## How I run the code

Two ways, pick whichever is comfortable that day:

1. **TypeScript Playground (easiest, no setup):** paste a file's code into
   [typescriptlang.org/play](https://www.typescriptlang.org/play) and hit **Run**.
2. **On my own machine (when I'm ready):**
   ```bash
   npm install          # one time, installs TypeScript
   npx tsx week-01-typescript-foundations/day-1-variables-and-types.ts
   ```
